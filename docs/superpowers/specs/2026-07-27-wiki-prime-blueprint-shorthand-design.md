# Wiki 查询后缀简写设计

## 目标

让 Wiki 查询和别名重定向在命中已知物品或别名后，自动识别以下系统级后缀：

- `p` 或 `P` 等同于 `Prime`
- `总图` 等同于 `蓝图`

管理员无需为每个物品重复添加 `物品p`、`物品p总图` 等组合映射。

## 优先级与解析规则

解析使用以下固定顺序：

1. 对原始输入执行 NFKC 规范化，同时保留字符位置和空格边界；另行生成忽略空格及大小写的匹配键。
2. 使用匹配键对完整输入执行精确别名查询。用户别名覆盖同名内置别名；精确命中后直接返回，不再应用后缀展开。
3. 未精确命中时，使用匹配键按照现有最长前缀规则寻找基础别名，但从保留边界的原始规范化输入中提取后缀。
4. 在删除后缀内部空格之前先验证基础别名与 `p`、`prime` 之间的连接边界。
5. 仅当基础别名匹配成功，且剩余内容完整符合下述后缀语法时，才展开系统简写。
6. 后缀不符合语法时不执行 `p` 或 `总图` 的语义改写，返回原输入并标记为未匹配。

后缀忽略内部空格和大小写，只接受以下完整组合：

```text
后缀 := Prime标记? 蓝图标记?
Prime标记 := p | prime
蓝图标记 := 总图 | 蓝图
```

至少应出现一个标记。因此允许 `p`、`prime`、`总图`、`蓝图`、`p总图`、
`p蓝图`、`prime总图` 和 `prime蓝图`；不允许逆序、重复或附带其他字符。

`p` 和 `prime` 的连接边界统一按基础别名的最后一个字符判断：

- 基础别名最后一个字符为中文时，允许紧邻或以空格分隔，例如 `圣英p`、`圣英 p`。
- 基础别名最后一个字符不是中文时，必须以至少一个空格分隔，例如 `wukong p`、`MK-1 p`、`咖喱2 p`。
- 因此 `wukongp`、`MK-1p` 和 `咖喱2p` 不在 Wiki 简写规则中展开。

市场查询已有独立的 `wukongp` 解析逻辑，不受上述 Wiki 边界限制。

展开前将规范名拆成 `基础名 + Prime? + 蓝图?` 的尾部结构，再按固定顺序重建为
`基础名 + Prime? + 蓝图?`，从而保持幂等。已有和新请求的同类标记取并集：

- `X Prime` 加 `p` 仍为 `X Prime`。
- `X 蓝图` 加 `p` 变为 `X Prime 蓝图`。
- `X Prime 蓝图` 加 `p总图` 仍为 `X Prime 蓝图`。

示例：

| 输入 | 解析结果 |
| --- | --- |
| `圣英` | `afentis` |
| `圣英p` | `afentis Prime` |
| `圣英P总图` | `afentis Prime 蓝图` |
| `咖喱p总图` | `Excalibur Prime 蓝图` |
| `wukong p总图` | `wukong Prime 蓝图` |
| `wukongp总图` | 不匹配系统简写，返回原输入 `wukongp总图` |
| `咖喱总图p` | 不匹配系统简写，返回原输入 `咖喱总图p` |
| `咖喱pp` | 不匹配系统简写，返回原输入 `咖喱pp` |

## 安全边界

- 不对未命中任何基础别名的任意英文单词展开末尾 `p`。
- 完整输入若存在精确别名，精确别名始终优先于前缀解释。
- ASCII 别名后的 `p` 必须有空格边界，因此即使存在 `Am` 别名，`Amp` 也不会解释为 `Am + p`。
- 用户自定义精确映射保持最高优先级，管理员仍可显式覆盖系统行为。
- 既有错误用户映射不会被自动删除；升级后可通过 `/wfmapdel 别名` 删除一次，使系统规则接管。

## 实现位置

- 在 `resolve_alias_only` 使用的纯别名解析路径增加后缀规范化，不向昵称 JSON 批量写入组合数据。
- 新规则作用于 `wk` 查询，以及 `/wfmapdel` 删除后用于展示恢复内置映射的同一解析路径。
- 市场查询继续使用现有商品解析与 `Prime`、蓝图修饰符逻辑，本设计不改变市场查询。
- 不修改灰机 Wiki 客户端的词条存在性判断或 URL 安全校验。

## 验证

- 覆盖允许的全部 `p`、`P`、`Prime` 与 `总图`、`蓝图` 组合及空格变化。
- 验证 `圣英 -> afentis`、`圣英p -> afentis Prime`、`圣英p总图 -> afentis Prime 蓝图`。
- 验证已有 Prime 或蓝图规范名不会产生重复标记。
- 验证用户精确映射覆盖系统展开，删除用户映射后恢复系统展开。
- 验证逆序、重复和附带其他字符的后缀返回原输入且标记为未匹配。
- 验证 ASCII 别名必须使用空格边界，`wukong p` 可展开而 `wukongp` 不展开。
- 验证即使存在 `Am` 基础别名，`Amp` 仍保持原样；若存在精确 `Amp` 映射则精确映射优先。
- 验证 `X Prime`、`X 蓝图`、`X Prime 蓝图` 的幂等重建结果。
- 验证 `/wk` 和无前缀 `wk` 得到相同的规范查询词。
- 运行完整测试集、编译检查和 `git diff --check`。
